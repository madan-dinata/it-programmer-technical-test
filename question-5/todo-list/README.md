# To-Do List

Aplikasi To-Do List sederhana yang dibuat menggunakan Spring Boot

## Fitur

- Menambah tugas
- Menampilkan daftar tugas
- Menandai tugas sebagai selesai
- Menghapus tugas

## Teknologi

- Java 17
- Spring Boot
- Thymeleaf
- Maven

## Penyimpanan Data

Data disimpan di memori menggunakan `ArrayList`, sehingga seluruh data akan kembali kosong ketika aplikasi dijalankan ulang.

## Cara Menjalankan

Pastikan Java dan Maven sudah terpasang, kemudian jalankan perintah berikut:

```bash
./mvnw spring-boot:run
```

Setelah aplikasi berhasil dijalankan, buka browser dan akses:

```text
http://localhost:8080
```
